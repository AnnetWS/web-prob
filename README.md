# Student CRUD (Flask + SQLite)

Веб-приложение для управления списком студентов: просмотр, добавление,
редактирование и удаление записей.

## Стек
- Python 3, Flask
- SQLite (встроенный модуль sqlite3)
- Jinja2 (шаблоны с наследованием)
- Bootstrap 5 (CDN)

## Архитектура
- Application factory (`create_app()`) — приложение создаётся функцией,
  а не глобальным объектом. Упрощает тестирование и конфигурирование.
- Соединение с БД хранится в `flask.g` — одно на запрос, закрывается
  в `teardown_appcontext`.
- `row_factory = sqlite3.Row` — доступ к столбцам по имени.
- Шаблоны наследуются от `base.html` (навигация, flash-сообщения,
  блок `content`).

## Что реализовано
- Полный CRUD: список, добавление, редактирование, удаление.
- Валидация на сервере: обязательные поля, возраст — целое число
  (обработка `ValueError`).
- Параметризованные SQL-запросы — защита от инъекций.
- Flash-уведомления с категориями.
- Подтверждение удаления на клиенте (`confirm`).
- Автосоздание таблицы при старте (`CREATE TABLE IF NOT EXISTS`).

## Структура
- `app.py` — вся логика приложения
- `templates/base.html` — общий layout
- `templates/students_list.html` — список
- `templates/student_form.html` — форма добавления/редактирования

## Запуск
    python app.py
